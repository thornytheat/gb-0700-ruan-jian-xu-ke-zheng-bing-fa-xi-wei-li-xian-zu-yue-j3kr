# 席位定义

lease_id、user保持字符串。CAD-Pro、cad归一为CAD。kind取online、offline、heartbeat、release、capacity、failover。start/end必须带时区并转换UTC。seats为正整数；capacity记录表示采购生效区间的席位上限；failover记录声明主备切换窗口，其seats仅作占位校验。

在线租约可由同租约同版本release提前结束；离线授权一直占用至原到期时刻，即使收到release仍保留。心跳不建立租约。租约采用最高版本；同版多条实体租约冲突隔离。采购区间可重叠，最高version优先，同最高版不同数量返回CAPACITY_CONFLICT。

并发使用半开区间[a,b)，结束同刻开始不重叠。采购边界必须切分并发段。超用责任按租约开始时间倒序、再按编号倒序分配，分配席位严格等于超用数量。超用席位小时为超用数量×秒数/3600，Decimal计算。此工具只核验约定席位数，不含厂商复杂许可证条款。

租约ID在产品内唯一；不同产品允许相同租约号。线上租约在start同刻release得到零时占用，离线仍保留原到期。

# 主备来源与切换裁决

可选第9列source记录记账服务：primary或standby（小写归一，空值视为primary，其他值隔离SOURCE）。同一租约号可同时在主、备两侧出现，接收端按(产品,租约号,类型,版本,开始,来源)去重，跨来源不算重复行。

切换裁决不盲信任一侧：仅当failover记录声明了该产品的切换窗口，窗口内主、备两侧对同一段使用（同产品、同使用人、同类型、同席位、同版本且区间相交，相交部分落在窗口内）的记录合并为一次占用；占用区间取并集，租约号优先取主侧编号。合并租约source为both，origins列出全部原始事件（行号、租约号、来源、区间），原始记录不因合并丢失。窗口外或仅单侧的记录各自独立计席，备服务实际承接的使用人不因合并或偏向主侧而漏计。合并租约的release可匹配组内任一原始租约号。

并发段按主/备/双源分列席位；名义峰值为关闭切换合并后的账面峰值，用于量化切换期重复记账的抬高；真实峰值与真实超用按合并后租约计算。与切换窗口相交的超用段标记failover=true。证据导出的failover_window、failover_merge行与工作台切换裁决面板给出同一结论。

同一批切换事件重试不新增占用：文件内完全重复的行按DUPLICATE_EVENT隔离；同一输入整体重跑复用同一批次编号。结果先序列化再写入，写入失败回滚并保留旧版。
